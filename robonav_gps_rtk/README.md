# GPS RTK

Septembre 2025

Real Time Kinetic est un protocole permettant d'acquérir des données GPS de haute précision (de l'ordre du cm) 

La mise en oeuvre et une liste de matériel est disponible sur le site du réseau Centipede https://docs.centipede.fr/

Pour des raisons de coût nous nous sommes tournés vers des module GPS Quectel de haute précision. Mais ce n'est qu'au mois de juillet 2025 que nous avons réussi à accéder à une précision centimétrique.

C'est l'équipe de développement 2025 - 2026 qui prendra en charge l'intégration au projet RoBoNav.

* Base_GPS_RTK : code source pour l'implantation d'une base RTK avec un module Quectel  LC29HDA (RTK)
* Client_GPS_RTK : code source pour l'implantation d'une rover RTK avec un module Quectel  LC29HDA (RTK)
* Ficher de log RoverRTK_Icam05092025
* Données de log significatives dans des fichiers Excel
